# SmartBI实施清单

## 1. 总体实施原则

- 建立“人员考勤市场投入主题模型”，在模型层统一人员、组织、考勤、出差、市场、规则、异常。
- 简单比例指标放在 SmartBI 计算字段中，复杂异常规则在数据库、ETL 或存储过程中预计算。
- 领导版使用大屏布局；工作员版使用分析型布局。
- 图表联动、参数过滤、跳转、浮动框、条件格式和清单导出使用 SmartBI 原生能力优先实现。
- 地图优先使用 SmartBI 地图组件；人员轨迹、热力矩阵等高级效果可使用 ECharts 扩展属性。

## 3. 计算字段建议

| 计算字段 | 公式 | 建议位置 |
| --- | --- | --- |
| 可用人天 | 在岗有效人数 × 工作日数 - 合规请假人天 - 其他豁免人天 | ETL/模型层 |
| 总部出差率 | 总部出差人天 / 总部可用人天 × 100% | SmartBI 计算字段 |
| 大区市场在岗率 | 大区市场有效人天 / 大区可用人天 × 100% | SmartBI 计算字段 |
| 人均市场天数 | 市场有效人天 / 有效人数 | SmartBI 计算字段 |
| 目标达成率 | 实际市场或出差天数/比例 / 目标要求 × 100% | SmartBI 计算字段 |
| 达标人数占比 | 达标人数 / 应考核人数 × 100% | SmartBI 计算字段 |
| 异常率 | 异常人天 / 可用人天 × 100% | SmartBI 计算字段 |
| 市场投入指数 | 40% × 目标达成率 + 25% × 市场在岗率 + 20% × 达标人数占比 - 15% × 异常率 | SmartBI 或 ETL |

## 4. 需要 ETL/SQL 预计算的内容

| 内容 | 原因 | 输出字段 |
| --- | --- | --- |
| 每日是否市场 | 需结合人员负责市场、定位、审批和豁免 | `is_market`、`market_id` |
| 每日是否出差 | 需结合审批和考勤状态 | `is_trip` |
| 审批地与实际地偏离 | 城市/经纬度匹配逻辑复杂 | `location_required`、`location_actual`、`deviation_value` |
| 连续异常 | 涉及跨日窗口计算 | `continuous_days`、`exception_level` |
| 多规则匹配 | 单位、岗位、层级、班子成员规则需优先级 | `rule_id`、`target_value` |
| 豁免扣减 | 请假、培训、借调、外派需统一处理 | `exemption_type`、`exemption_days` |
| 异常结果 | 异常中心和闭环需要稳定事实表 | `fact_attendance_exception` |

## 5. 筛选器配置

| 筛选器 | 字段 | 作用范围 |
| --- | --- | --- |
| 日期范围 | `dim_calendar.date` | 全局 |
| 单位 | `dim_org.unit_id` | 全局 |
| 大区 | `dim_org.region_name` | 全局 |
| 部门 | `dim_employee.department` | 总部、人员清单 |
| 职务/层级 | `dim_employee.position_level`、`position_name` | 全局 |
| 是否班子成员 | `dim_employee.is_leader` | 全局 |
| 人员 | `dim_employee.employee_id` | 明细和画像 |
| 考勤状态 | `fact_attendance_daily.attendance_status` | 明细 |
| 异常类型 | `fact_attendance_exception.exception_type` | 异常中心 |
| 是否达标 | 计算字段或结果字段 | 对比和清单 |

## 6. 联动与跳转规则

| 触发对象 | 动作 | 参数 |
| --- | --- | --- |
| KPI 卡片 | 跳转专题页 | `topic`、日期范围、组织范围 |
| 单位排行条形图 | 联动全屏 | `unit_id` |
| 异常类型图 | 筛选异常清单 | `exception_type` |
| 地图点位 | 展示地点人员列表 | `province`、`city`、`market_id` |
| 异常清单人员行 | 打开个人画像浮层 | `employee_id`、日期 |
| 日期热力格 | 下钻当日人员状态 | `date`、`unit_id` |
| 导出按钮 | 导出异常明细 | 当前筛选条件和权限范围 |

## 7. 权限配置

| 角色 | 数据范围 | 展示规则 |
| --- | --- | --- |
| 高层领导 | 全公司 | 可看全量指标、单位排名和人员明细 |
| 大区负责人 | 本大区 | 可看大区内单位和人员明细 |
| 单位负责人 | 本单位 | 可看本单位明细，不看其他单位敏感对比 |
| 工作人员 | 授权范围 | 可看明细和导出权限内数据 |
| 普通人员 | 本人或不开放 | 不展示敏感对比和他人明细 |

## 8. 验收检查项

- 所有 KPI 口径在语义模型中可追溯。
- 单位排名默认使用市场投入指数，不使用绝对人天数。
- 异常能下钻到人、日期、地点、状态和原因。
- 组织权限对页面展示和导出同时生效。
- 演示环境人名脱敏。
- 地图在无经纬度时可按省市级展示。
- 领导版和工作员版布局区分清楚。
